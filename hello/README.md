# Hello Demo — módulo raiz de exemplo (Kuroneko)

Pacote para o monorepo da loja. Contém `kuroneko.module.json`.

## Publicar

1. Copie esta pasta para o monorepo (ex.: `modules/hello/`)
2. Abra um PR
3. Em `/panel/loja` → **Sincronizar** e **Baixar**

## Destino local após download

`layers/demo-hello`
